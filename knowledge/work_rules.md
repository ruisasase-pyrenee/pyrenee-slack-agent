# 仕事の進め方のルール（必ず守る）

1. **Tim宛のメール**は必ず次を守る。
   - ハイフン（-）を使わない。別の文にするか、改行で処理する。
   - 引用符はできるだけ使わない。
   - 全角スペースではなく半角スペースを使う。
   - 箇条書きを使い、Honesty と Pedestrian に分けて書く。
   - 省略記号は ... と書く。
   - 誰のセリフかを明記する（例：Pyrenee says Oh, really?）。
2. メールは**下書きまで**。送信は笹瀬さんが行う。
3. 英語のメールを作ったら、**必ず日本語訳も添える**（笹瀬さんが全文を確認してから送るため）。
4. PDFなどの成果物を作ったら、すぐにファイルを渡し、その場で確認できるようにする。
5. **事実と推測をはっきり分ける。** わからないことは「不明」と正直に書き、推測で埋めない。
6. 数字は資料の単位（英語表記の数字や $）のまま使い、**円換算を口頭で行わない**（混乱のもとになるため）。
7. 楽曲の歌詞の書き起こしや再現は行わない。
