## 4. 製品：Pyrenee Drive（ピレニードライブ）

### 概要 [提供]
- 後付け型のAIドライブアシスタント。ダッシュボードに置いてシガーソケットに挿すだけで使える、弁当箱サイズのデバイス。
- カメラとAIで道路上の歩行者や自動車を検知し、衝突リスクを予測する。危険を察知すると音声でドライバーに知らせ、事故を防ぐ。
- 置き場所とシガーソケットがあれば、どんな車にも後付けできる。**先進安全装備のない既販車や古い車を安全にできることが最大の特徴。**
- カメラはルームミラーの下に、車載スクリーンと揃う位置に設置する。
- 2019年に発表し、グッドデザイン賞を受賞。
- 現在はモックアップのプロトタイプ段階（テストとデータ収集に使用）。**最終版は2027年1月ローンチ予定。**

### 技術 [提供]
- ハードウェアとAIの両方を自社開発。
- 基盤モデルは OpenAI の GPT を使用し、用途に特化したハーネスを自社開発。
- 3Dカメラ（ステレオカメラ）を使用。
- 検出対象：車、トラック、歩行者、自転車、バイク。
- UI：AIキャラクターが音声の波形に合わせて1.2倍に拡大・縮小する。
- 方針：フィジカルAIの開発を目指す。AIに個性や寿命を持たせるという、倫理面を考えた製品コンセプトを検討中。

### 仕様（会社案内PDF 2025年4月版・社内メモ）[資料]
| 部品 | スペック |
|---|---|
| SoC | NVIDIA GPU/CPU（社内メモでは Jetson Orin NX） |
| フロントカメラ | Full HD ステレオカメラ、視野角120° |
| ドライバーカメラ | Full HD シングルカメラ、視野角120° |
| ディスプレイ | 6.5インチ タッチパネル液晶、1,920x480 |
| 通信 | 4G/LTE、Wi-Fi、Bluetooth、GPS |
| センサー | 加速度、ジャイロ、温度、照度、気圧 |
| 電源 | シガーソケット 12V（全世界共通なので同じ仕様で世界展開できる） |

### 機能（会社案内PDF）[資料]
- 事故防止：見落としを防ぎ、「右の自転車に注意」のように音声と画面で警告する。
- 学習して進化する危険予測：全デバイスがクラウドでつながり、各車両が経験したシーンを追加学習する。
- ナビゲーション、通話、オンラインドライブレコーダー、テレマティクス。
- 法人向けのフリート管理ダッシュボード（車両の稼働状況、走行距離、アラート、緊急通報の件数）。※PDFの画面はコンセプト用のイメージ。
- データの収集と活用（利用者の許諾を得た運転・交通・街のデータ）。

### デモの内容 [提供]
- 実機のハードウェア
- リアルタイム検出
- 衝突停止テスト
- 横断歩道での歩行者検知と進行方向の予測（まだ車道に出ていない歩行者の動きから危険を予測する）

## 5. ピッチの核（市場に対する主張）[提供]

1. **交通事故の死者数は、戦争・犯罪・災害の死者の合計より多い。**
2. その90%以上が人のミス（脇見、判断ミス）によるもの。だからAIが介入できる余地が非常に大きい。
3. **自動ブレーキへの反論（最大の武器）**
   - JNCAPや Euro NCAP の評価試験は直線が中心。
   - しかし実際の事故の60%以上はカーブと交差点で起きている。
   - 自動車メーカー自身も、自動ブレーキだけでは防ぎきれないと認めている。
4. 事故は3段階で起きる（原因の発生 → 衝突に向かう → 事故）。Pyrenee Drive は第1段階の「予防安全」を担い、自動ブレーキ（第2段階）やエアバッグ・シートベルト（第3段階）の手前で効く。[資料]

### 市場規模（会社案内PDF）[資料]
- 国内 7,800万台、世界 15.7億台。
- アメリカ 2億9,200万台、中国 2億9,400万台、その他の先進国 4億2,500万台、新興国 4億8,500万台。
- 乗用車、トラック、バスなど、すべての車種が販売対象。

## 8. 政策上の位置づけ [提供]

2026年7月に公表された「日本成長戦略」の17の戦略分野のうち、Pyrenee は次に当てはまる。
- (1) AI・半導体：① フィジカルAI、③ バーティカルAI（領域特化型AI）
- (2) デジタル・サイバーセキュリティ：⑥ 自動運転技術
- 成長戦略全体の軸は「強みをいかすフィジカルAIの競争優位の確立」。

- 製造産業局 自動車課：TEL 03-3501-1511（内線 3831〜3836）
