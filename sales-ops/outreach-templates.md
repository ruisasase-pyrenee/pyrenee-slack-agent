# Outreach Templates (First Agri / matcha B2B leads)

Reusable snippets. The `lead-to-outreach` skill fills these in automatically; kept here so they can be copied by hand too, and so the style stays consistent as it evolves.

## WhatsApp — short version (default, use this unless asked for more)

```
Hi {first_name},

I'm Rui, Global Sales Manager at First Agri — {how_they_reached_us, e.g. "saw your inquiry via our website"}. Thanks for reaching out!

{one line: recommended SKU(s) + why, e.g. "I've attached our lineup — our FA002 is specifically engineered for lattes..."}. Happy to send a sample so your team can test before ordering.

{optional, only if Rui is traveling: "I'm currently in {city} and will be in Australia through this month — happy to visit if that works for you."}

Best,
Rui
First Agri Inc.
```

Keep under ~120 words. No headers, no bullet lists — this is a chat message.

## Email — longer version (use only if Rui asks for a formal email instead of/in addition to WhatsApp)

```
Subject: Following up: {topic} – Wholesale Quote for {company}

Hi {first_name},

Thank you again for reaching out about {use_case}. Following up on our automated reply...

[volume-tiered pricing paragraph]
[clarifying questions: delivery cadence, packaging/private-label, target price]
[sample offer + shipping address ask]
[offer to call/visit]

Best regards,
Rui Sasase
First Agri Inc.
```

"Hi {first_name}, this is Rui from First Agri — following up on the matcha samples/quote we discussed over WhatsApp. Do you have a couple of minutes to talk through your store rollout and what you're comparing us against, so I can get you an accurate quote?"
