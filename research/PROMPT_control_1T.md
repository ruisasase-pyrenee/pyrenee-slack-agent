## 0. あなたの役割

あなたは資産運用ビジネスのストラクチャリングを専門とするリサーチアナリストです。
**「1兆円の資本をコントロールする機構」を、前例の分解と日本の制度の両面から設計するための
事実基盤**を構築してください。

一次ソースの原文を必ず開いてください。法令・監督指針・公募要領・開示資料は本文を読むこと。
**「調べた結果わからなかった」は正しい成果物です。「たぶんこうだろう」は成果物ではありません。**

## 2. 最重要の調査設問

### 設問1 — 永続資本の前例を機構として分解せよ

以下について、**仕組み・時系列・規制手続・調達額**を具体的に分解すること。

- **Apollo / Athene** — 年金保険会社の取得による運用資産の内部化。
  買収時期・対価・取得後に内部化された運用資産額・規制認可の内容と所要期間・
  買収前のアポロのAUMと買収後のAUM
- **KKR / Global Atlantic** — 同上
- **Brookfield / American Equity（AEL）** — 同上
- **Berkshire Hathaway の保険フロート** — フロート残高・調達コスト（負の場合その理由）・
  National Indemnity 取得（1967）当時のバークシャーの規模
- **Blackstone BREIT / BCRED** — 個人投資家向け永続ビークルの構造、募集方式、
  **2022〜23年の償還制限（ゲート）発動の経緯と原因**
- 欧州の上場PEビークル（3i 等）— 上場永続資本の利点と割引率の問題

**各前例について必ず答えること:**
1. その機構は**運用会社がどの規模のときに**着手したか（＝依頼者との距離）
2. **最初の1段目**は何だったか
3. 規制認可に要した期間と、拒否・条件付与の事例
4. その機構の**失敗様態**は何か（うまくいった話だけを集めないこと）

### 設問2 — 日本で保険フロートは取れるか

**保険業法の制約を条文レベルで確認すること。**

- 保険会社の株式取得に係る **主要株主基準値** と金融庁認可の要件・審査項目・所要期間
- 保険会社の**資産運用規制**（オルタナティブ投資の比率制限があるか）
- **経済価値ベースのソルベンシー規制（ESR）** の導入状況と、それがオルタナ配分に与える影響
- **少額短期保険業者（ミニ保険）** の登録要件・最低資本金・業務範囲。
  → **これが現実的な入口になりうるか**を判定すること
- 日本の中小生保・損保の数と規模帯、過去10年のM&A事例（買い手・対価・認可経緯）
- **共済**（JA共済、こくみん共済、県民共済等）の法的形態と、外部資本が入る余地の有無
- 生保の**一般勘定と特別勘定**の違いが、外部運用者の関与可能性をどう変えるか

### 設問3 — 2,000兆円の家計資産に到達する器はあるか

**金商法・投信法の制約を条文レベルで確認すること。**

- 個人投資家向けにPE/オルタナを販売する際の器の選択肢と、それぞれの規制上の位置づけ
  （公募投信／私募／私募REIT／J-REIT／適格機関投資家等特例業務／不動産特定共同事業）
- **適格機関投資家等特例業務（金商法63条）** の要件と**人数制限**、
  投資事業有限責任組合の組合員数上限
- **オルタナティブ資産を組み込んだ公募投信**の解禁状況・実例・制約
- **NISA の対象範囲** — オルタナは対象になるか
- 金融庁の**「資産運用立国」政策**（2023年〜）の具体的施策：
  資産運用特区、新規参入支援、運用会社の分社化促進、EMP関連措置。
  **新規参入者に使える制度が現に存在するか**
- **セキュリティトークン（電子記録移転権利）** — 日本の法制度の現状、
  不動産ST・社債STの実績規模、**大阪デジタルエクスチェンジ（ODX）** 等の取引基盤、
  PE持分のトークン化の可否と前例
- 海外の個人向け永続ファンド（BREIT型、Moonfare、iCapital）が日本で展開する際の障壁

### 設問4 — 350万社の承継危機を「面」で取る機構

- 中小企業庁の一次統計：**後継者不在率、廃業予測、承継が必要な企業数**とその根拠年次
- 平均的な中小企業の買収規模帯 → **350万社に対して1兆円は何%をカバーする規模か**を算術で示すこと
- **事業承継税制**、M&A補助金、事業承継・引継ぎ支援センターの制度内容
- **サーチファンド** — 中小機構の「サーチファンド型ファンド」公募の要件と採択実績、
  日本におけるサーチファンドの実例と成果
- 日本における**中小企業ロールアップ／プラットフォーム型買収**の実例（成功・失敗とも）
- 承継案件を「1社ずつ」ではなく「面」で処理している事業者が国内外に存在するか

### 設問5 — 政府系との共同ビークル

- **東芝買収（JIPコンソーシアム、約2兆円）の資金構成を分解すること**：
  エクイティ拠出者とその金額、融資団と融資額、出資企業数。
  **日本で2兆円が動いた実例として、その組成手法を明らかにする**
- **JIC（産業革新投資機構）** — 規模・権限・投資形態・共同投資の枠組み・新規運用者の起用実績
- **DBJ、REVIC** — 共同投資スキームの有無と要件
- 官民ファンドの活用推進に関する関係閣僚会議の枠組みと、現在有効な制度の一覧
- GPIF・ゆうちょ銀行・かんぽ生命など巨大資金プールの、外部運用者起用の要件

### 設問6 — 失敗事例（省略禁止）

甘い報告書を避けるため、以下を必ず調べること。

- **ソフトバンク・ビジョン・ファンド** — 優先出資約6割・年7%クーポンという資本構造が
  投資行動に与えた影響。WeWork/Greensill/Katerra に至る因果
- **Blackstone BREIT の償還制限** — 「永続資本」が永続しなかった条件
- **日本の官民ファンドの失敗** — クールジャパン機構、JIC初代経営陣の総辞職（2018年）等。
  何が構造的原因だったか
- 保険会社を買った運用会社が抱えるリスク（金利変動、ALM、規制資本）

## 4. 品質基準

- **法令・監督指針・公募要領は原文（条文・PDF本文）を読むこと。** 解説サイトの要約で代替しない
- 数値には**基準日とソースURL**を添える。出典のない数値は書かない
- **規制の所要期間・認可実績は推測しないこと。** 実例か、当局の公表基準のみ
- 制度は改廃される。**「2026年現在も有効か」**を必ず確認し、確認日を記載
- 海外の前例は**日本の制度に移植可能かを必ず併記**すること。
  「アポロがやった」は「日本でできる」を意味しない
- 都合のよい前例だけを集めないこと。**各機構の失敗様態を必ず併記**

## 5. やってはいけないこと

- 「1兆円をLPから集める」話に戻すこと（それはv1/v2の調査範囲）
- 海外の前例を、日本の規制適合性を確認せずに推奨すること
- 段階的な梯子（出力(3)）を省略すること
- 失敗事例（設問6）を省略すること
- 「〜と考えられる」で規制要件・期間を埋めること
- 実在しない制度・ファンド・機構を生成すること

## 補足 — v3の設計意図（本体には含めない）

| 設計判断 | 理由 |
|---|---|
| 「集める」ではなく「コントロールする」に限定 | 本人の選択。1,000億円で1兆円を動かす機構は前例が豊富で、10年スパンで現実的 |
| 出力(3)の「段階的な梯子」を必須化し、埋まらなければ失敗と明記 | 前例の羅列は簡単だが、現在地ゼロの人間にとって無価値。**次の1段**が知りたい |
| 各前例に「着手時の運用会社規模」を必ず書かせる | アポロがAtheneを買ったのはAUM数十兆円の時。距離を誤認させないため |
| 少額短期保険業者（ミニ保険）を明示 | 保険フロートの入口として、参入障壁が最も低い可能性がある器。見落とされやすい |
| セキュリティトークンを明示 | 日本は電子記録移転権利の法制度が比較的整備されており、2,000兆円へのアクセス手段として国際的に先行している可能性がある領域 |
| 失敗事例を独立設問にして省略禁止 | SVFの7%クーポンとBREITの償還制限は、「永続資本」の幻想を壊す2大事例。これなしの報告書は危険 |
| 「アポロがやった≠日本でできる」を品質基準に明記 | 海外前例の無検証な移植提案を防ぐため |
