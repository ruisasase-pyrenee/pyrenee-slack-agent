## 2. 最重要の調査設問

以下の6問への回答精度を、リストの網羅性より優先してください。

1. **運用実績のない1号ファンドに実際に出資した実績のあるLPは、具体的にどこか。**
   過去5年（2021〜2026）の事例を、ファンド名・LP名・出資時期・金額・ファンド総額で列挙。
   **国内・国外の双方**を対象とすること。これが本調査で最も価値の高いアウトプット。

2. **「1号ファンド／エマージング・マネージャーへの出資」を明示的な投資方針として掲げるLPは誰か。**
   国内外を問わず、ファンド戦略として first-time / emerging manager を対象にしている主体
   （専門FoF、GPシーディング、GPステークス、機関投資家のEMPプログラム）を特定すること。
   **v1で完全に見落としていた層であり、本ファンドと構造的に最も相性がよい。**

3. **50億円という規模は、各LPの最低投資額・分散規定に照らして受け入れ可能か。**
   「1ファンドへの出資は総額の10〜20%以内」という上限と、「1件あたり最低◯億円」という下限の双方を確認し、
   50億円ファンドと両立するかを候補ごとに判定すること。

4. **外国LPが日本のLPSに出資する際の実務上の障壁は何か。それは回避可能か。**（§5で詳述）

5. **プライベートバンク／ウェルスプラットフォーム経由で個人・ファミリーオフィス資金を集める道は
   実在するか。** 日本のPBが国内PEファンドを顧客に販売する実務、フィーダー組成のコストと最低ロット、
   金商法上の制約を確認すること。

6. **1号ファンドが最初に取るべきLP攻略順序はどれか。** 根拠つきで提示すること。

## 5. 外国LP受入れの実務論点（設問4）★v2の新設

**「出資してくれるか」と「出資できる器があるか」は別問題です。** 以下を必ず調べてください。

1. **恒久的施設（PE）認定リスク** — 外国LPが日本のLPSに出資した場合に日本での課税対象と
   みなされるリスク。**租税特別措置法41条の21（投資組合に係る特例）** の適用要件
   （非居住者・外国法人の組合員が受ける特例、業務執行への不関与要件、持分割合要件等）を
   条文と国税庁通達から確認すること。
2. **源泉徴収** — 分配金に対する源泉徴収の要否・税率、租税条約による軽減。
3. **LPS法上の制約** — 投資事業有限責任組合契約に関する法律における外国LP・海外投資比率の制限。
4. **ストラクチャー選択肢** — 日本LPS単体／ケイマン等のパラレルファンド／フィーダー構造の
   それぞれについて、組成コスト・運用コスト・所要期間の実務相場。
5. **外国LPが求める運営要件** — 監査法人（Big4要否）、報告通貨（USD報告の要否）、
   ILPAレポーティング準拠、四半期報告、ESG/DEIポリシー、KYC/AML、FATCA/CRS対応。
6. **為替** — 円建てファンドへの外貨投資におけるヘッジ実務とコスト負担者。

**この章の結論が「外国LPは実質不可能」であっても、それは有効な成果物です。**
その場合は障壁を具体的に特定してください。

## 6. 適格性スコアリング

| 観点 | 配点 | 満点の条件 |
|---|---|---|
| 1号ファンド出資可否 | 0〜4 | 1号ファンドへの出資**実績が確認できる** |
| EM特化度 | 0〜3 | first-time / emerging manager を**明示的な投資方針**に掲げる |
| チケットサイズ整合 | 0〜2 | 最低額・上限額とも50億円ファンドと両立 |
| 日本投資実績 | 0〜2 | 日本のファンドへの投資実績が確認できる |
| 戦略適合 | 0〜2 | 国内グロース／対象セクターへの明示的関心 |
| 到達可能性 | 0〜2 | 公募制度あり、または現実的な紹介経路が特定できる |

**減点**
- 運用実績3本以上を要件化 → −3
- 最低出資額が5億円超（50億円の10%上限と衝突）→ −2
- 日本のファンドへの投資実績が皆無、かつ日本進出の言及もなし → −2
- 外国LPで、§5の障壁が未解決 → −1
- 直近2年のファンド新規出資がゼロ → −1
- 制度が終了・休止中 → 対象から除外し、除外理由を明記

## 8. 品質基準

- **一次ソースの原文を開くこと。** PDFはダウンロードして本文を読む。
  検索スニペットだけを根拠に数値を確定させない。
- 数値には必ず**基準日とソースURL**を添える。出典のない数値は書かない。
- 推定値は必ず「推定」と明記し、推定の根拠を1行で示す。
- 企業年金・ファミリーオフィスの個別データは大半が非公開。
  **公開されていないものを「公開されていない」と報告することは、正しい仕事です。**
- 制度・公募・プログラムは改廃される。**「現在も有効か」を必ず確認**し、確認日を記載。
- 海外主体は**実在確認を必ず行うこと**。本プロンプトに挙げた社名は出発点であり、
  正確性を保証するものではない。存在しない、または事業を終了している場合はそう報告すること。
- 担当者の氏名・連絡先といった個人情報は収集不要。組織・部署・役職レベルで十分。
