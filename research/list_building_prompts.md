# デーツ営業先リスト獲得：使うサイト・AIとプロンプト集

## 1. 使うサイト（目的別）

| 目的 | サイト | 使い方 |
|---|---|---|
| 店舗の洗い出し | Googleマップ | 「halal」「ハラール」「インド食材」「Asian grocery」をエリア名と組み合わせて検索。住所・電話・営業時間・口コミ・写真で、デーツが棚にあるかまで確認できる |
| 店舗の洗い出し | 食べログ・Yahoo!マップ | Googleマップに載っていない店の補完。閉店表示の確認にも使う |
| ハラール店の一覧 | Halal Gourmet Japan（halalgourmet.jp）、Halal Food in Japan（halalfoodinjapan.com） | ムスリム向けの店舗・モスク検索サイト。食材店のカテゴリで絞り込む |
| ハラール認証の取得先 | 日本ハラール協会（JHA）、日本アジアハラール協会（NAHA）、ジャパン・ハラール・ファンデーション | 認証を取った企業・店舗のリスト。卸・メーカーの発掘に使う |
| モスクの所在地 | 早稲田大学 店田研究室（imemgs.com）のモスク一覧 | モスクの周辺に食材店が集まるので、訪問エリアを決める起点にする |
| 企業の基本情報 | 国税庁 法人番号公表サイト、gBizINFO | 正式な社名・所在地を確認する。電話番号は載っていない |
| 企業・店舗数 | ajsm.jp（全国スーパー情報）、各社のIR・会社概要 | チェーンの本社・店舗数を確認する |
| 営業リストDB（有料） | SalesNow、Baseconnect／Musubu | 業種・地域で企業を絞り込み、CSVで書き出す |
| 卸・輸入業者 | スーパーデリバリー（卸サイト）、楽天・Amazonの出品者情報 | 「デーツ」で検索し、販売元や輸入者を拾う。競合調査にもなる |
| バイヤーと会う | FOODEX JAPAN、スーパーマーケット・トレードショー、ハラールEXPO系の展示会 | 出展者リストから競合と卸を拾う。来場するバイヤーに直接会う |
| 公的な支援 | JETRO、東京都中小企業振興公社 | 輸入品の商談会、バイヤーとのマッチング事業 |
| コミュニティ | Facebookグループ（在日バングラデシュ・パキスタン・インドネシアなどの国別コミュニティ）、Instagramの店舗アカウント | 個人店の新規開店や、ラマダン時期の需要を拾う |

## 2. 使うAI（役割別）

| AI | 向いている作業 |
|---|---|
| Claude（Web検索・リサーチ機能つき） | 出典つきの調査、表にまとめる作業、重複の除去、優先順位づけ |
| Perplexity | 出典URLつきですばやく調べる。店舗1件ずつの裏取りに向く |
| ChatGPT／Gemini の Deep Research | テーマ単位の広い調査（例：都内のハラール食材店の網羅） |
| Googleマップの抽出ツール（Apifyなど） | エリアとキーワードで店舗情報を一括で書き出す。各サイトの利用規約を確認してから使う |
| HubSpot（CRM） | 集めたリストを取り込み、訪問・商談の状況を管理する |

**どのAIでも守ること**：電話番号やメールアドレスはAIがもっともらしく作ってしまうことがあります。プロンプトで「出典URLがないものは不明と書く」と必ず指定し、使う前にGoogleマップか公式サイトで確認してください。

## 3. プロンプト集

### プロンプト① エリアごとの店舗の洗い出し（独立系）

```
あなたは東京の食品販路リサーチャーです。
東京都【エリア名：例 新大久保・大久保】にある、ハラール食材店・中東/南アジア/東南アジア系の食材店を、できるだけ漏れなく洗い出してください。

■ 探し方
- Googleマップ、食べログ、Halal Gourmet Japan、Halal Food in Japan、地域のブログ記事を横断して調べる
- 検索語の例：「halal food 新大久保」「ハラール 食材 新大久保」「indian grocery Okubo」「nepali store Shin-Okubo」
- 閉店・移転の表示がある店は、その旨を書いたうえで残す

■ 出力（表形式）
店舗名 / 住所 / 最寄駅 / 業態（小売・卸・両方） / 想定客層の国籍 / デーツ取扱の有無と産地（口コミ・写真で確認できた場合のみ） / 電話 / 営業時間 / 出典URL / 確度（高・中・低）

■ 厳守事項
- 電話番号・メールは推測で書かない。出典で確認できないものは「不明」
- 1店につき出典URLを1つ以上
- 最後に、見つからなかった情報と、次に確認すべきことを3行で
```

### プロンプト② チェーン本部の取引窓口の調査

```
あなたは食品メーカーの新規開拓担当です。
次の小売チェーンについて、新規取引を申し込む窓口を調べてください：【企業名を列挙】

■ 調べる場所（この順で優先）
1. 各社公式サイトの「お取引をご希望の方へ」「商品のご提案」「法人のお問い合わせ」
2. 会社概要・IR資料
3. 展示会・自治体の商談会の募集要項

■ 出力（表形式）
企業名 / 運営会社 / 本社所在地 / 都内店舗数 / 窓口の部署名 / 申込方法（Webフォーム・メール・展示会・代理店経由） / 申込に必要な書類 / 返信までの目安 / 現在のデーツ取扱（品種・産地・価格・内容量） / PBの有無 / 出典URL / 確度

■ 厳守事項
- 消費者向けのお客様相談室の番号は、取引窓口として書かない
- 確認できない項目は「不明」と書き、推測で埋めない
```

### プロンプト③ 店舗1件ずつの裏取り

```
次の店舗について、今も営業しているか、デーツを売っているかを確認してください。
店舗名：【店舗名】 住所：【住所】

確認すること：
1. 営業中か、閉店・移転していないか（Googleマップ・食べログの最新の表示、最新の口コミの日付）
2. デーツを売っているか（口コミ、写真、Instagram、ECの商品ページ）。売っていれば、産地・品種・価格・内容量
3. 仕入れの担当者や店主の名前（公開情報で確認できる場合のみ）
4. 公式の連絡手段（電話・Instagram・Facebook・Webサイト）

出力は箇条書きで、各項目に出典URLと確認した日付をつけてください。見つからない項目は「不明」と書いてください。
```

### プロンプト④ 卸・輸入業者（ハブと競合）の洗い出し

```
日本国内でデーツ（なつめやしの実）を輸入・卸している企業を洗い出してください。
特に、UAE（ドバイ）産・サウジ産・イラン産を扱う企業と、ハラール食材の卸を重点的に調べてください。

■ 探し方
- 「デーツ 輸入 卸」「デーツ 業務用」「dates importer Japan」で検索
- スーパーデリバリーなどの卸サイト、楽天・Amazonの販売元・輸入者の表示
- 日本ハラール協会などの認証取得企業リスト、展示会の出展者リスト

■ 出力（表形式）
企業名 / 所在地 / 扱う産地・品種 / 荷姿（小袋・1kg・5kg・10kgカートン） / 販売先（小売・飲食・製菓） / 直輸入か国内仕入か / 公式サイトURL / 出典URL / 当社との関係（提携候補・競合・両方）

■ 厳守事項
- 電話・メールは推測で書かない
- 最後に「提携を打診する価値が高い上位5社」と理由を1行ずつ
```

### プロンプト⑤ 展示会の出展者リストからの抽出

```
【展示会名：例 FOODEX JAPAN 2026】の出展者リストから、次に当てはまる企業を抜き出してください。
- ドライフルーツ・ナッツ・デーツを扱う企業
- 中東・南アジア・ハラール食品の輸入・卸の企業
- 輸入食品を扱う小売・卸のバイヤーが参加している企業

出力：企業名 / ブース番号（分かれば） / 扱う商品 / 当社にとっての位置づけ（販路・提携・競合） / 出典URL
出展者リストで確認できない情報は「不明」と書いてください。
```

### プロンプト⑥ 集めたリストの統合・優先順位づけ

```
添付した複数の営業先リスト（CSV）を1つにまとめてください。

1. 重複を除く（店名の表記ゆれ、英語とカタカナの違い、同じ住所を同一とみなす）
2. 次の基準で A・B・C の優先度をつける
   - A：デーツをすでに扱っている、またはムスリムの客が多く、店主が仕入れを決められる
   - B：エスニック食材店だが、デーツを扱っているか不明
   - C：閉店の疑い、連絡手段が不明、デーツと客層が合わない
3. 同じ日に回れるよう、エリアごとに並べる（徒歩圏でまとめる）
4. 出力列：優先度 / エリア / 店舗名 / 住所 / 電話 / デーツ取扱 / アプローチ方法（直接訪問・フォーム・卸経由） / 出典URL / 確度 / 次にやること

推測で補った項目には「要確認」と書いてください。
```

### プロンプト⑦ HubSpotへの取り込み用に整える

```
次の営業先リストを、HubSpotの「会社」として取り込めるCSVに整えてください。

列：Company name / Street address / City（東京都＋区市） / Phone number / Website URL / Industry（小売・卸・飲食） / Lifecycle stage（Lead） / 優先度（A/B/C） / アプローチ方法 / 出典URL / 確度
- 電話番号は 03-xxxx-xxxx の形式にそろえる
- 不明な項目は空欄にする（「不明」という文字は入れない）
```
