# 日本成長戦略 起点・投資対象拡張プロンプト

日本成長戦略（2026年7月21日 閣議決定）と「官民投資ロードマップ」を起点に、
**投資対象の候補範囲を意図的に広げる**ためのプロンプト集。

想定用途: 銘柄・投資先の発掘、自社の参入領域探索、事業提携先の洗い出し。
投資助言ではなく、候補の網羅と仮説出しのための道具として使う。

---

## 1. メインプロンプト（投資対象の拡張）

PDF（日本成長戦略本文／概要／官民投資ロードマップ）を添付したうえで、以下を貼る。

```
あなたは政策と産業構造の両方を読む調査アナリストです。目的は「有名な受益企業を並べること」ではなく、
まだ市場が織り込んでいない投資対象を、論理で漏れなく埋め尽くすことです。

# 入力
- 一次資料: 添付の「日本成長戦略」本文・概要・戦略17分野の官民投資ロードマップ
- 投資主体: {個人／事業会社／CVC。例: スタートアップ経営者の個人ポートフォリオ}
- 資金規模: {例: 数百万〜数千万円}
- 時間軸: {例: 3〜10年、2030年と2040年のマイルストーンを見る}
- リスク許容度: {例: ミドル。個別株の集中は3割まで}
- すでに検討済み・除外したい対象: {例: 大手半導体装置・総合商社・メガバンク}
- 実行可能な市場: {例: 日本株、米国株、投信・ETF、未上場は原則不可}

# 禁止事項（重要）
- 誰でも思いつく大型銘柄の列挙で終わること
- 一次資料の記述（分野・品目・政策手段）に紐付かない候補を挙げること
- 「関連銘柄」という曖昧な理由付け。必ず「何の需要が、いつ、誰の売上になるか」を書く
- 事実と推測の混在。推測には必ず【推測】と明記する

# 手順（すべての軸を必ず一周すること。軸ごとに最低3件、重複は不可）

STEP 0. 資料の要素分解
  17分野と「主要な製品・技術等」を表に落とす。各品目について
  (a) 目標（数量・シェア・年次） (b) 道筋 (c) 政策手段（補助金／税制／政府調達／規制改革／
  基金・投資枠／標準化・国際連携）を抜き出す。原文の表現を引用し、出典ページを付す。

STEP 1. バリューチェーン展開軸
  各品目を「原料・鉱物 → 素材・部素材 → 製造装置 → 部品 → 完成品 → 実装・工事 →
  運用・保守 → データ／ソフト → リユース・リサイクル」に分解し、各層の担い手を挙げる。
  完成品メーカーより、上流と運用・保守を厚く見ること。

STEP 2. イネーブラー軸（ピック＆ショベル）
  分野に関係なく、投資が実行されると必ず消費される共通財を洗う。
  電力・送配電・変圧器・受変電、冷却・熱、クリーンルーム、EPC・プラント工事、
  計測・検査・分析、産業用ガス・薬液、認証・試験・規格、物流・保管、
  人材（施工管理・技能工・研究者）、保険、リース・ファイナンス、セキュリティ。

STEP 3. 物理ボトルネック軸（逆張りの本命）
  「政策が資金を出しても、物理的に足りないので価格が上がる／納期が伸びるもの」を特定する。
  電力容量、変圧器、水、用地、クリーンルーム、船台・ドック、GPU、レアアース・重要鉱物、
  熟練工、検査装置、輸送インフラ。ボトルネックを握る企業・資産を候補に加える。

STEP 4. 交差点軸
  17分野のうち2つ以上に同時に効くものを抽出する（例: AI×電力、防衛×造船×港湾物流、
  核融合×マテリアル、コンテンツ×情報通信）。交差点は需要が二重に来るので優先度を上げる。

STEP 5. 政策手段の受益者軸
  政策手段の種類ごとに「誰の口座に金が入るか」を逆算する。
  ・政府調達 → 直接の受注者と、その1次・2次下請け
  ・補助金・投資枠 → 設備を売る側（受け取る側より確実に儲かるのは誰か）
  ・税制優遇 → 設備投資が前倒しになる業種
  ・規制改革 → 参入障壁が消えて新市場が立つ側／既得権を失う側（ショート候補）
  ・標準化・国際連携 → 海外市場を取りに行ける側

STEP 6. 時間軸の分解
  「先行27品目（〜2028年）」「2030年目標」「2040年目標」の3段に候補を仕分ける。
  それぞれ、いつ受注が計上され、いつ株価・事業に反映されるかを書く。
  今年の予算・補正で動くもの（短期）と、2030年代まで売上が立たないもの（長期）を混同しない。

STEP 7. 資産クラスと地理の拡張
  上場大型／上場中小型／未上場・スタートアップ／海外上場（日本の政策が海外企業の需要になる場合）／
  ETF・テーマ投信／実物資産（データセンター、港湾、工業用地、電源）／コモディティ／
  事業投資・M&A・業務提携。さらに「日本が輸入依存している相手国側」の供給者も見る。

STEP 8. 反証（必ず実施）
  ここまでの候補を、次の基準で自ら潰す。
  ・政策期待だけで実需の発注書が来ないもの
  ・すでに株価・バリュエーションに織り込み済みのもの
  ・補助金依存で、売上は増えるが利益率が上がらないもの
  ・政権交代・予算縮小で消える蓋然性が高いもの
  ・競合が多く、価格決定力を持たないもの
  潰した理由も明記し、生き残った候補にだけ優先度を付ける。

# 出力フォーマット
まず、生き残った候補を優先度順に表で出す。

| # | 候補（企業・資産・領域） | 紐付く分野・品目 | 拡張軸 | 何の需要が誰の売上になるか | 価格決定力 | 収益化時期 | 織り込み度 | 確認すべき一次情報 | 確度(高/中/低) |

表の後に、以下を付ける。
1. 「盲点トップ5」— 一般的な関連銘柄リストにはまず出てこないが、論理的に外せないもの。理由を各3行。
2. 「今週中にできる検証アクション」— 決算資料の該当ページ、受注残の見方、政府の入札公告・
   予算項目など、次に見るべき具体的な一次情報を5つ。
3. 「この見立てが外れるとしたら何が起きた時か」を3つ。

# 検証ルール
- 数値・企業名・政策内容は、資料に書いてあること／自分の推測／要確認、を必ず区別してラベルする
- 添付資料に書かれていないことを、書かれているかのように述べない
- 曖昧な結論より、間違いうるが検証可能な仮説を出す
```

## 2. 追撃プロンプト（メインの後に続けて使う）

### 2-1. ボトルネック逆引き

```
STEP 3で挙げた物理ボトルネックのうち、最も解消が難しい順に3つ選び、それぞれについて
「この制約を握っている、もしくは制約を解消して対価を得る主体」を10件挙げてください。
上場・未上場・海外・実物資産を問いません。各件について、代替されるとしたら何によってかも書いてください。
```

### 2-2. 交差点の深掘り

```
17分野の総当たりマトリクス（17×17）を作り、2分野が同時に効くマスのうち、
公開の解説記事でほとんど語られていない組み合わせを10個挙げてください。
各組み合わせについて、共通して必要になる製品・技術・サービスを具体名で3つずつ書いてください。
```

### 2-3. 中小型・未上場への降ろし込み

```
これまでの候補のうち、時価総額1000億円未満の日本企業と、未上場スタートアップに絞って
再構成してください。各社について、日本成長戦略のどの品目のロードマップに、
どの政策手段（補助金／政府調達／規制改革）経由で接続するかを1文で書き、
接続が薄いものは正直に「薄い」と書いてください。
```

### 2-4. 自社事業側への転用（投資ではなく参入判断に使う場合）

```
私の会社は{事業内容}です。ここまでの分析を、金融投資ではなく「自社の投資・参入判断」に読み替えてください。
(1) 既存アセットで今すぐ取りにいける品目 (2) 3年かければ取れる品目
(3) 取りにいくべきでない品目 に分け、それぞれ根拠と、最初の一手（誰に会い、どの公募に出すか）を書いてください。
```

### 2-5. 反対尋問

```
あなたが挙げた優先度上位5件について、それぞれ「これは買うべきでない」と主張する側の
最も強い反論を書いてください。反論に耐えられなかったものは撤回してください。
撤回ゼロなら、反論が甘いということです。
```

---

## 3. 使い方のコツ

- **PDFは必ず添付する。** 記憶だけで書かせると、分野名や金額を平気で捏造する。
- **STEP 0 を省略させない。** ロードマップの「政策手段」の欄が、実は一番の金脈。
- **1回で全部やらせない。** メイン → 2-1 → 2-3 → 2-5 の順に分けると精度が上がる。
- **除外リストを最初に渡す。** 「すでに検討済み」を明示するほど、出力が周辺部に押し出される。
- 出てきた候補は、必ず一次情報（決算説明資料の受注残、政府の入札公告、予算項目）で裏を取る。
  このプロンプトの成果物は仮説であって、結論ではない。
