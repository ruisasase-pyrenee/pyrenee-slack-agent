## 2. 結論（改訂）

**自社デラウェア法人をスポンサーとするE-2ビザが、最安かつ最速の本命ルート。**

- 米国法人を自社で持っている以上、Deel EOR（月額$899）を使う必然性は薄い。EOR経由ではそもそも**E-2もL-1も取得できない**（E-2は「日本資本の企業」自身が、L-1は「グループ会社」が雇用主である必要があり、Deelが雇用主になると要件を満たさない）。EORで取れるのは実質H-1B（抽選）/O-1のみ。
- E-2は**抽選なし・年中申請可・在東京米国大使館で完結（USCIS申請不要）**。日本人は最長5年のマルチプルビザ。配偶者は就労可。

## 4. E-2成立のための確認事項（重要・弁護士確認前提)

1. **国籍要件**: デラウェア法人の究極的な株主構成で、日本国籍者の保有比率が**50%以上**であること。「出資者はほぼ日本」なら満たす可能性が高いが、キャップテーブルでの正式確認が必須。今後米国VC等の出資で50%を割るとE-2の基盤が崩れる点も中期リスクとして認識しておく。
2. **投資の実在性**: 資金が「デラウェア法人を経由して日本に流れている」だけだと、**米国事業への実質的な投資（at-risk資本）と認められない恐れ**がある。米国事業としてのオフィス・雇用・支出など、米国内での事業実態(substance)の作り込みが論点。
3. **限界性（Marginality）**: 生活維持を超える収益力または雇用創出計画が必要 → 事業計画書でカバー。
4. **申請者の適格性**: 各申請者が日本国籍で、役員・監督者・不可欠なスキル保有者のいずれかに該当すること。
   - 三野（代表・創業者）→ 役員(Executive)として最も通りやすい
   - 野口（社長室）→ 監督者または不可欠スキルでの整理が必要
   - 笹瀬 → 職務内容に応じ管理職または不可欠スキルでの整理が必要

| **E-2** | **不要**。役員・監督者・不可欠なスキルのいずれかに該当すればよく、学歴ではなく役職・職務・経験で判断される |
| **L-1** | **不要**。日本法人での1年以上の勤務と、管理職または専門知識職であることが要件 |

### 笹瀬のL-1が難しい理由（正確な整理）
- L-1の要件は「申請前3年以内に、海外グループ会社で**継続1年以上の雇用**」。2025年3月参画なら2026年7月時点で約1年4ヶ月であり、**期間自体は既に満たしている**。
- 本当のブロッカーは**業務委託契約であること**。L-1は雇用主-従業員関係（payroll上の雇用）が前提で、業務委託期間は原則「qualifying employment」にカウントされない。
- 対処するなら「日本法人で正社員化→1年経過を待ってL-1」だが、それでは2027年半ば以降になる。
- **E-2にはこの勤続要件が存在しない**。デラウェア法人（またはE-2企業）に不可欠スキル従業員として採用される形なら、過去の契約形態・勤続年数は要件にならない → 笹瀬の現実的なルートはE-2一択。

### O-1の「その後の採用」問題（懸念は正しい）
- O-1は**個人の卓越性に紐づく属人的なビザ**。三野が取得できても、他メンバーや将来の採用者には一切波及しない。1人ずつ別のビザ戦略が必要になり、スケールしない。
- 対して**E-2は企業登録型**。一度デラウェア法人がE-2条約投資家企業として大使館に登録されれば、**以後の日本人採用（監督者・不可欠スキル人材）はE-2従業員ビザを1人$3,000〜5,000程度・数週間〜2ヶ月で追加発給**でき、採用チャネルとして使い回せる。「その後の採用」問題への直接の解になる。

### 戦略の選択肢
1. **全員E-2で統一（最安・最速・推奨）**: 企業登録1回で3名＋将来の採用までカバー。概算は§3のとおり（3名で約210〜420万円）。
2. 三野・野口をL-1A、笹瀬をE-2とする混合案: L-1Aは**EB-1C（多国籍企業幹部の永住権）への直結ルート**があるのが唯一の優位点。ただし新規オフィスL-1は初回1年のみ＋更新コストがかかる。永住権を急がないなら、まずE-2で渡米し必要になった時点でL-1A/グリーンカードに切り替える方が資金効率が良い。
3. O-1（三野のみ）: チーム渡航・採用の解決にならないため、E-2の国籍要件（日本資本50%）が万一崩れた場合のバックアップと位置付けるのが妥当。

## 5. Deelへの再提案（依頼内容の変更）

EOR前提の見積依頼から、以下に切り替える：

1. **Deel Immigrationで、自社（デラウェア法人）スポンサーのE-2申請サポートが可能か**、可能な場合の費用見積
2. E-2が難しい場合の代替（新規オフィスL-1）の費用見積
3. 雇用管理はEORではなく**Deel US Payroll／PEO**での提供内容と費用
4. 無料ビザ適格性チェック（E-2の国籍要件・投資実態の初期判定を含む）
