# BLOCK B｜技術の分水嶺 — Starship

**3行要約:** 耐熱シールドは「外部専門家の悲観」と「実飛行データの改善＋会社の確信」が対立したまま、Flight 14（8月末）が事実上の判定戦。会社は金属タイルの並行試験でヘッジ済み。失敗してもFalcon 9＋Starlinkで会社は成立する。

## B1. 耐熱シールド論争（左右併記）

| 弱気（外部） | 強気（会社＋実データ） |
|---|---|
| 元NASA専門家3名（PICA-X共同発明者Rasky氏ら）「急速再使用には行き止まり」（Bloomberg 7/29・B級情報） | 約18,000枚中の脱落は数枚レベル（複数の独立映像・B級） |

**決着条件:** Flight 14/15で連続して脱落最小＋実際の再飛行間隔の短縮が示されれば強気側で決着。逆に大規模脱落が再現すれば弱気側。

## B3. 完全再使用までの残り関門

# BLOCK C｜堀の耐久性

**3行要約:** 5要素の堀はいずれも直近で「試されて生き残った」。周波数はFCCがAmazonに時間ペナルティを課してSpaceX優位を実質温存、競合は実測で1桁以上後方。崩壊シナリオは「Starship失敗×競合再使用成功」の同時発生のみ。

## C1. 参入障壁5要素

| 要素 | 崩壊条件 | 直近の兆候 |
|---|---|---|
| 打ち上げコスト | 競合の再使用実用化 | なし（各社未達） |
| 量産能力 | 衛星週産の失速 | なし（10,200機稼働） |
| 周波数権益 | FCCの先行者利益否定 | **試されたが温存**（C2） |
| 政府信頼 | 契約の実削減 | なし（Q2にStarshield$6B新規） |
| 資本力 | 資金市場の閉鎖 | なし（IPO$85.7B＋債券$25B調達済み） |

## C2. 周波数の判例分析（今回の核心）

FCC DA 26-553: Amazon Leo（配備331機＝計画10%）にマイルストーン免除を与えたが、**代償として2026/7/30以降配備分の周波数優先権を最長2028/3/30まで剥奪**。SpaceXの「先送りせよ」要求は退けられたが、実質は時間ペナルティでSpaceX優位を保全。8月時点でAmazonは短縮certification未提出＝**ペナルティ発動中**。
→ 弱気読み:「規制は障壁を軟化し得る」／強気読み:「軟化してもなお後発に20ヶ月の税」— **ペア併記の上で強気側がやや優勢**（Amazonの物理的遅延が理由）

## C3. 競合実測

| 競合 | 実測 |
|---|---|
| Amazon Leo | 329機（計画の10%）・ペナルティ下 |
| 中国 千帆 | 約200機（報道B級） |
| ULA/Ariane/Blue/Neutron | 再使用の商業実証なし |
| Falcon 9 | 年2,500トン軌道投入 = 世界シェア80-90%（L1） |

## C4. 反例研究: Intel

「無敵」だったIntelは①プロセス移行失敗（技術の分水嶺で転倒）②TSMCという代替供給者の成熟③設計顧客の離反、で10年で堀を失った。SpaceX翻訳: ①=Starship失敗 ②=競合再使用成功 ③=政府・ハイパースケーラーの調達分散。**①と②の同時発生が唯一の構造的崩壊経路**（現時点で両方の兆候なし）。

**鮮度トリガー:** Amazon Leoのcertification提出 or 配備加速／Neutron初飛行
