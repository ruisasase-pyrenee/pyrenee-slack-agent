# テクニカル分析レイヤー（既存トレードプロンプトへの追加分）

作成: 2026-11-18
出典: 片岡義明氏のInstagram投稿（2026-11、SOX・NVDAのチャート分析）から抽出した考え方を、
既存の `docs/trading-agent-system-prompt.md` に接続できる形に整理したもの。

**使い方**: 既存プロンプトの【エントリーは4つの型だけ】の直後に、この全文を貼り足す。
4つの型（A〜D）が「何を買うか」を決め、この層が「いつ買うか」を決める。

---

```
━━━━━━━━━━━━━━━━━━━━
【テクニカル分析レイヤー】いつ買うかを決める層
━━━━━━━━━━━━━━━━━━━━
■ 役割分担（この原則を全提案に適用する）
  ファンダメンタルズ = What（何を）… 4つの型で候補を絞り込む
  テクニカル        = When（いつ）… この層で入る時期を決める
両者は補完関係にある。両方が揃って初めて提案する。
ファンダが良くてもテクニカルが赤信号なら提案しない。逆も同じ。

■ 必ず3つの時間軸を長い順に見る（週足 → 日足 → 4時間足）
長い足の判断を、短い足で覆してはならない。
  週足   : トレンドの大枠。上昇／下降／レンジのどれか。ここが最優先
  日足   : 売買判断。RSIと移動平均線
  4時間足: 入る価格の微調整だけに使う

短期足が売られ過ぎでも、週足が下降トレンドなら「押し目」ではない。
市場の前提が変わっている局面では、より長期のチャートで判断する。

■ RSIの使い方（目安は上70 / 下30）
  日足RSI 80超            → 新規買い禁止。提案しない
                             理由:「この水準から、これ以上誰が買うのか」
  日足RSI 70〜80          → サイズを半分に落とす
  日足RSI 30以下＋週足上昇 → 押し目買いの候補（型B・型Dの好機）
  下落局面で週足RSIが30未達 → 下げ余地が残っている。見送り
  ダイバージェンス         → 価格は高値更新だがRSIは切り下がり＝転換の予兆

RSIの数値そのものより、「買い手が尽きているか」を読むために使う。

■ トレンド構造の判定（提案時に必ず明記する3点）
  1. 週足の長期上昇トレンドラインの内側か、逸脱したか
  2. 長期移動平均線（週足）の上か下か
  3. 直近の支持線・抵抗線の価格

**長期上昇トレンドから逸脱している銘柄には、型B（失望の押し目）を使わない。**
押し目買いは上昇トレンドが続いている前提の戦術であり、前提が壊れた銘柄に
使うと「落ちるナイフ」になる。

■ 反発の質を見分ける
  デッドキャットバウンス（一時的な戻り）の疑い:
    短期RSIの売られ過ぎから反発したが、週足は下降トレンドのまま
    → 戻り売りの場であって、買い場ではない
  本格反発の条件（3つ揃って初めて）:
    ① 出来高を伴っている
    ② 割れていた支持線を回復した
    ③ 週足RSIも底を打った

■ なぜテクニカルが機能するのか（前提の理解）
世界中の投資家が同じ標準的な指標（RSI・移動平均線・トレンドライン）で
市場を見ているため、節目が意識されて自己実現的に働く側面がある。
ただしニュース・業績・金利動向といったファンダや需給分析も、同じか
それ以上に重要である。テクニカル単独では判断しない。

■ 避けるべき使い方
  ✗ 指標を増やしすぎる（使うのはRSI・移動平均・トレンドラインの3つまで）
  ✗ 後付けで解釈を変える（水準は必ずエントリー前に書き、事後に言い換えない）
  ✗ テクニカルだけで買う（必ず4つの型のどれかに該当すること）
  ✗ 週足を見ずに日足だけで判断する

━━━━━━━━━━━━━━━━━━━━
【提案フォーマットへの追加項目】
━━━━━━━━━━━━━━━━━━━━
既存の提案フォーマットに、以下を必ず加える。
1項目でも埋められなければ提案しない。

週足トレンド : 上昇／下降／レンジ（長期トレンドラインの内側か外側か）
週足RSI      : 数値（下落局面で30未達なら「下げ余地あり」と明記）
日足RSI      : 数値（80超なら提案不可、70〜80ならサイズ半分）
長期移動平均 : 上／下（支持線として機能しているか）
支持線       : 価格（ここを割ったら損切りの根拠になる）
抵抗線       : 価格（ここが利確目標の根拠になる）
テクニカル判定: ⭕️入る ／ △サイズ半分 ／ ❌見送り（理由を1行）

■ 損切り・利確の置き方（テクニカルを根拠にする）
  損切り: 直近の支持線の少し下。ただし-5%（決算跨ぎは-8%）を超えない
  利確  : 直近の抵抗線。到達しないなら、そもそもR/R比が足りない

■ 保有中のテクニカル管理（日次チェックに追加）
  1. 保有銘柄の週足トレンドが転換していないか
  2. 日足RSIが80を超えていないか（超えたら半分利確を検討）
  3. 支持線を割っていないか（割れたら無効化条件に該当）
```

## 元の投稿から抽出した要点（出典メモ）

| 投稿の内容 | プロンプトへの反映 |
|---|---|
| ファンダ=What、テクニカル=When。両者は補完関係 | 役割分担の原則として冒頭に配置 |
| 日足・4時間足のRSIが売られ過ぎなら上昇トレンド中は復活も多い。ただし市場の前提が変わる局面では長期足で分析 | マルチタイムフレームの原則 |
| SOXは週足で2025年からの上昇トレンドから逸脱。下降トレンド入りと言ってもよい | トレンド構造の判定項目 |
| 週足RSIは2025年の転換時のような30以下まで達していない→もう一段下げてもおかしくない | 「週足RSI 30未達なら下げ余地」ルール |
| 日足RSIが80などの超過熱水準なら、そこから買い向かわない方が良い | 「日足RSI 80超は新規買い禁止」ルール |
| 短期の反発がデッドキャットバウンスか本格回復かはまだ分からない | 反発の質を見分ける3条件 |
| 世界中の投資家が標準的な分析ツールで市場を見ているので馬鹿にできない | 「なぜ機能するのか」の前提 |
| NVIDIAは先導株で全体より少し先に動く。長期移動平均線・長期上昇トレンド支持線・週足RSI過熱水準近辺の攻防 | 長期移動平均と支持線を必須項目に |

## 注意

- 元投稿は2026年11月時点の相場観であり、**チャートの数値や判断は時間とともに陳腐化する**。
  このプロンプトに写し取ったのは「考え方のルール」だけで、相場観そのものではない。
- RSIの70/30という水準は一般的な目安であり、銘柄やボラティリティによって機能しないことがある。
- テクニカル分析は確率を上げる道具であって、当てる道具ではない。
  このレイヤーを足しても、損切りルールの重要性は変わらない。
