## 今日やること（この順番）

### [ ] 1. ログインパスワードを変更 ← 最優先

漏れたのは部店・お客様コードとログインID。楽天証券のログインは
「部店・お客様コード＋ログインID＋パスワード」なので、**3要素のうち2つが相手の手にある**。
残っているのはパスワード1枚だけ。

```
PCサイト → マイメニュー → 基本情報（マイナンバー・ログイン関連）
  → ログインパスワード・取引暗証番号 → ログインパスワードの「変更」
  → 現在のパスワード / 新しいパスワード / 確認用の再入力 → 確定
```

- 他サービスとの使い回しをやめる
- 生年月日・電話番号から推測できるものを避ける（447万口座の区分では
  年収・資産情報まで対象。相手は本人を装いやすい）
- ログインID自体は変更できない。楽天市場の楽天会員IDとは別物

### [ ] 2. 取引暗証番号を再設定

パスワードを変えても、注文の実行に使う暗証番号が別にある。両方変える。

```
同じ画面 → 取引暗証番号の「再設定・変更」
  → 登録携帯電話番号を確認 → Webでの再設定・変更手続きへ
  → SMSでワンタイムキーを送信 → SMSの6桁を入力 → 次へ
  → 新しい取引暗証番号を2回入力 → 確定する
```

### [ ] 3. パスキーを登録 ← フィッシング対策の本命

偽サイトにパスワードを入れても、パスキーは**そのドメインでしか動かない**ので盗めない。
OTPやSMSは偽サイト経由でリアルタイムに中継（AitM）されるが、パスキーは原理的にそれが効かない。

```
セキュリティ設定 → パスキー認証に変更
  → 作成画面のログインIDが自分のものか確認
  → iPhone「パスキーを追加」 / Android「続行」
  → 顔認証・指紋認証 → 作成完了画面を確認
```

- 最後に一度ログアウトして「パスキーでログイン」から入れるか確認する
- すでに使えているなら作り直さなくてよい
- **「パスキーを再登録してください」というSMSには従わない**（これ自体が詐欺の手口）

### [ ] 4. 出金先変更ロック ← 自分の使い方に一番合う設定

**取引制限を一切かけずに、資金の持ち出し経路だけ塞げる。** 売買は続けられる。

```
0120-862-274（カスタマーサポート）に電話
  → 「出金先指定口座の変更機能をロックしたい」と依頼
  → 適用状況と、将来変更したいときの手続きも確認しておく
```

※ 「取引やサービスの一時的な利用停止」を設定すると出金先変更も制限されるが、
   それは取引も止まる設定。取引を続けたいならこの電話での依頼が正解。

### [ ] 5. ログイン通知・注文通知を全部ON

```
セキュリティ設定 → ログイン通知 → 設定変更へ → 利用する → 設定
セキュリティ設定 → 注文通知 → 変更 → 対象商品を「通知する」 → 変更する
```

- **普段売買しない商品も含めて全部ONにする。** 不正注文は使っていない商品で来る
- 登録メールが今も受信できるか、迷惑メールに埋もれていないか確認
- 出金依頼の受付時にも登録メールへ通知される

### [ ] 6. パスキーの保存先（Apple / Google）も守る

**iPhone**
```
設定 → 自分の名前 → サインインとセキュリティ → 2ファクタ認証
  → 有効か / 信頼できる電話番号が今の番号か確認
設定 → 自分の名前 → 下までスクロールして端末一覧
  → 見覚えのない端末 → アカウントから削除
設定 → Face IDとパスコード → パスコード入力
  → 盗難デバイスの保護をオン → セキュリティ継続が必要を「常に」
```

**Google**
```
Gmailアプリ → 右上のアイコン → Googleアカウントの管理 → セキュリティ
  → 2段階認証プロセス（無効なら有効化）
  → お使いのデバイス → すべてのデバイスを管理 → 知らない端末をログアウト
  → 再設定用の電話番号・メールアドレスが今も使えるか確認
```

不正な端末があれば削除・ログアウトに加えてパスワードも変更。
**自分が操作していないのに届くログイン承認は絶対に許可しない。**

## 取引制限をかけるかどうか（判断が必要）

### かけるべき理由
楽天証券の補償は被害額の50%が基本で、**「お客様がもともと保有していた証券を売却された」分は
補償対象外**。攻撃者が保有株を売って別の銘柄を買う（ランプ＆ダンプ）タイプの被害は、ほぼ自腹。

### かけない理由
実際に売買しているので、止めると機会を失う。

### 推奨
**上の1〜6を全部やって、取引制限はかけない。** 異変が出た瞬間に 0120-852-638 で止める構えにする。
1〜6だけでパスワード経路・フィッシング経路・出金経路は塞がる。

### かける場合の選択肢と注意

| 選びたいこと | 選ぶ設定 |
|---|---|
| 投信の買付・積立だけ残す | 投資信託の買付以外を停止 ※投信の定期売却も止まる |
| 投信の売買と出金を残す | 投資信託と出金以外を停止 |
| 外国株だけ止める | 外国株式のみ停止 ※**米国株を買っているなら買付が止まる** |
| 全部止める | ログイン・すべての取引を停止 ※積立も止まる。解除は電話のみ |

```
マイメニュー → セキュリティ設定 → 再認証
  → 取引の一時的な利用停止タブ → 取引やサービスの一時的な利用停止 → 設定
  → 制限内容を選択 → 認証へ進む
  → 登録電話番号を選択 → ワンタイムキーを通知
  → 【電話の音声】で6桁を確認（メールではない） → 入力 → 次へ
  → 完了画面を確認し、セキュリティ設定に戻って反映を確認
```

**⚠️ 注意**
- **指値・逆指値注文を出したままだと、制限解除時に意図しない価格で約定する可能性がある。**
  先に保留中の注文を確認する
- **2026年11月15日 午前3時より前**に設定した利用停止には出金先変更の制限が付いていない。
  以前設定したものをそのまま使っているなら、制限内容を変更するか、一度解除して同じ内容を再設定する
- 解除したまま放置しない

## 異変があったときの緊急停止

身に覚えのない取引がある / ログインできない / スマホを盗まれた

```
0120-852-638（自動音声・原則24時間）に自分から電話
  → 音声案内に従って本人確認
  → 「ログインを含むすべてのお取引の制限」を選ぶ
```

Webから操作できるなら、セキュリティ設定で「ログイン・すべての取引を停止」も選べる。
不審な取引があった場合は、停止に加えてカスタマーサポート（0120-862-274）にも連絡。

## 詐欺の見分け方

名前も住所も出金先の銀行も知っている。**それでも本物の証明にはならない。**
447万口座の区分では、氏名・住所・電話番号・メールアドレス・出金先口座・年収・資産情報が
対象になっている。相手がそれを全部知っていても不思議ではない。

- 届いた連絡に言われるまま操作しない。自分で公式サイトを開く
- **確認コードを相手に読み上げない**（これが最後の砦）
- 「あなたの口座を保護するために認証してください」→ 詐欺の定型句
- 「パスキーを再登録してください」というSMS → 従わない
