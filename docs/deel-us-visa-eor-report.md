# Deel面談報告：米国ビザスポンサーシップ（EOR）について

- **日付**: 2026年7月6日
- **面談相手**: Deel 浅岡 倭 氏
- **報告者**: 笹瀬
- **テーマ**: 米国法人を持たない当社が、DeelのEOR（Employer of Record／雇用代行）を通じて米国で就労ビザを取得・雇用する場合の選択肢と費用

---

## 1. 前提：EORスキームとは

当社に米国法人がなくても、Deelの米国法人が「法的雇用主」となり、ビザスポンサーシップ・給与支払い・社会保険・税務を一括代行する仕組み。当社はDeelとEOR契約を結び、月額費用を支払う。

## 2. ビザの選択肢（Deel提示）

| ビザ | 概要 | 抽選 | 費用目安 | 取得期間 |
|---|---|---|---|---|
| **H-1B**（専門職） | 最も一般的。学士号以上を要する専門職が対象 | **あり**（年1回、例年3月登録・10月就労開始） | $6,000〜13,500／件 | 通常3〜6ヶ月 |
| **L-1**（企業内転勤） | グループ会社間の異動が対象 | なし | 個別見積 | 個別 |
| **O-1**（卓越能力） | 高い実績要件（受賞歴・著名性等） | なし | 個別見積（弁護士費用が高くなりやすい） | 個別 |
| **TN** | カナダ・メキシコ国籍者のみ | なし | 低コスト | 短期 |

- 優先処理（Premium Processing）は **+$2,800** で審査15暦日に短縮（任意）。
- 正確な費用・適格性は、Deelの**無料ビザ適格性チェック**で個別に判定される。

## 3. Deel EORの費用体系（提案資料より）

| 項目 | 金額 | 備考 |
|---|---|---|
| EORプラットフォーム費用 | **$599/月/人**（ビザ不要時）<br>**$899/月/人**（ビザ必要時） | 年間契約・月次払い。毎月24日請求、5日以内支払 |
| ビザ取得サポート費用 | 一時金・**個別見積** | 上記月額とは別に初期費用として発生 |
| 給与・社会保険・税金 | 実費 | 毎月24日請求 |
| デポジット（保証金） | 給与を含む**1〜2ヶ月分の総費用** | 解約時に全額返金（未払い精算後） |
| 送金管理手数料 | $5/振込 | |
| オフボーディング費用 | $599 or $899/回/人 | 退職手続き時 |
| 早期解約手数料 | $599/回/人 | 契約後6ヶ月以内の解約時 |
| 就労許可証の確認サービス | $250/回/人 | Deel発行以外のビザ保有者の入社可否アセスメント |

## 4. 最安で渡米できるシナリオ（コスト比較）

※日本国籍を前提とすると、TN（カナダ・メキシコ国籍限定）は対象外。

### シナリオA：H-1B・通常処理（最安の新規取得ルート）★推奨
- ビザ実費：**$6,000〜**（レンジ下限、Premium Processing $2,800を使わない）
- EOR月額：$899 × 12ヶ月 = $10,788/年
- ほかにデポジット（返金あり）＋ビザサポート一時金（個別見積）
- **制約**：年1回の抽選（例年3月登録→当選後、10月1日就労開始）。抽選に外れると翌年待ち。申請時期を逃さないことが費用面より重要。

### シナリオB：O-1（抽選なし・時期自由）
- 抽選リスクゼロで最短渡米が可能だが、実績要件が高く、弁護士費用がかさむ傾向。H-1Bより総額は高くなりやすい。

### シナリオC：L-1（企業内転勤）
- 抽選なしだが「グループ会社間の異動」が要件。当社に米国関連法人がない＋雇用主がDeel（EOR）になる構成では要件充足が難しい可能性が高く、**適格性チェックでDeelに要確認**。

### シナリオD：既に米国就労資格を保有している場合（最安）
- Deelのアセスメント$250＋EOR月額$599のみ。ビザ取得費用ゼロ。ただし現状該当なし。

### 結論
**「H-1Bを通常処理・最低限の費用構成で申請し、抽選に乗る」のが最安ルート**（目安：一時費用$6,000台〜＋月額$899＋返金性デポジット）。次回のH-1B抽選（2027年度分：2027年3月登録見込み）に間に合わせるため、逆算してDeelの無料ビザ適格性チェックを早めに受けるのが得策。急ぐ場合・抽選リスクを避けたい場合はO-1だが費用増。

※参考：H-1Bの政府申請費用等は制度上**雇用主側の負担が原則**のため、社内では「会社負担の初期費用」として予算化が必要。

## 5. 導入フロー（Deel案内）

1. アカウントセットアップ（[手順ガイド](https://help.letsdeel.com/hc/en-gb/articles/4407745597969-How-to-sign-up-as-a-client)）
2. 法人審査（1営業日）※Partner ID・TAX IDに当社の法人番号を入力
3. EOR契約書作成と利用確認
4. デポジット支払（給与1ヶ月分＋社会保険・税金＋EOR費用1ヶ月分）＋ビザ申請料支払
5. オンボーディング
